# 数据备份软件代码设计说明

## 1. 程序目标

本程序实现一个命令行数据备份工具，支持将源目录中的文件和子目录备份到指定目录，并可根据备份清单恢复数据、校验备份完整性。

## 2. 模块划分

### 2.1 命令行入口

文件：`src/main.cpp`

职责：

- 解析用户输入命令。
- 支持 `backup`、`restore`、`verify` 三个核心动作。
- 解析 `--overwrite`、`--ext`、`--max-size` 等选项。
- 输出操作结果统计。

### 2.2 备份管理模块

文件：`include/BackupManager.h`、`src/BackupManager.cpp`

职责：

- 递归扫描源目录。
- 按筛选条件决定是否备份文件。
- 复制文件并保持相对目录结构。
- 生成备份清单。
- 根据清单恢复文件。
- 根据清单校验备份文件完整性。
- 阻止将备份目录放在源目录内部，避免递归备份自身。

主要数据结构：

- `BackupOptions`：保存备份选项，包括扩展名筛选、最大文件大小、文件名关键词、路径关键词、修改时间范围、是否覆盖。
- `OperationStats`：保存操作统计，包括目录数、文件数、跳过文件数、失败文件数、字节数。

### 2.3 清单模块

文件：`include/Manifest.h`、`src/Manifest.cpp`

职责：

- 保存每个备份条目的相对路径、文件大小、修改时间、校验值、是否目录。
- 将清单写入 `manifest.sbm`。
- 从 `manifest.sbm` 加载清单。

清单格式：

```text
SBM1
F|docs/a.txt|10|1783310000|123456789
D|empty|0|1783310000|0
```

其中第一列表示条目类型，`F` 是文件，`D` 是目录。

### 2.4 文件工具模块

文件：`include/FileUtils.h`、`src/FileUtils.cpp`

职责：

- 计算文件 FNV-1a 校验值。
- 转换文件修改时间。
- 处理跨平台路径字符串。
- 规范化扩展名。

### 2.5 打包归档模块

文件：`include/ArchiveManager.h`、`src/ArchiveManager.cpp`

职责：

- 将备份目录中的清单和文件数据打包为单个 `.sba` 文件。
- 从 `.sba` 文件解包出备份目录。
- 解包后重新生成 `manifest.sbm`。
- 解包时校验文件内容，发现损坏立即报错。
- 支持 RLE 压缩和对应解压。
- 使用 OpenSSL EVP 库函数实现 AES-256-GCM 加密和解密。
- 使用 OpenSSL PBKDF2-HMAC-SHA256 从密码和随机 salt 派生 256 位密钥。

归档格式：

```text
SBA1 magic
entry_count
entry_type path_length path size modified_time checksum file_bytes
```

SBA4 将清单条目和文件内容顺序拼接到一个大文件中，并记录压缩标志、加密标志、载荷长度、随机 salt、随机 IV 和 GCM 认证 tag，符合打包/解包、压缩/解压、加密/解密扩展功能要求。

### 2.6 图形界面

文件：`src/gui_win.cpp`、`build_gui.ps1`

职责：

- 提供原生 C++ Win32 图形界面。
- 支持输入源目录、备份目录、归档文件和还原目录。
- 支持执行备份、打包、解包、还原、校验。
- 支持启用 RLE 压缩和输入加密密码。
- 通过调用同目录下的 `sbm.exe` 复用核心 C++ 后台逻辑。

### 2.7 备用图形界面

文件：`gui.ps1`

职责：

- 提供 Windows Forms 图形界面。
- 支持选择源目录、备份目录、归档文件和还原目录。
- 支持执行备份、打包、解包、还原、校验。
- 支持勾选 RLE 压缩和输入加密密码。

## 3. 核心流程

### 3.1 备份流程

1. 检查源目录是否存在。
2. 检查备份目录是否位于源目录内部。
3. 根据 `--overwrite` 决定是否清理旧备份目录。
4. 递归扫描源目录。
5. 对目录创建对应目标目录并记录清单。
6. 对普通文件执行扩展名和大小筛选。
7. 对普通文件执行文件名关键词和路径关键词筛选。
8. 对普通文件执行修改时间筛选。
9. 复制符合条件的文件。
10. 计算文件校验值。
11. 写入 `manifest.sbm`。

### 3.2 还原流程

1. 读取备份目录中的 `manifest.sbm`。
2. 创建还原目标目录。
3. 按清单逐项创建目录或复制文件。
4. 对还原后的文件重新计算校验值。
5. 若校验值不一致，则报告错误。
6. 将清单中记录的修改时间恢复到目标文件。

### 3.3 校验流程

1. 读取备份清单。
2. 检查每个文件是否存在。
3. 比较实际文件大小和清单记录大小。
4. 重新计算文件校验值并比较。
5. 输出有效或损坏结果。

### 3.4 打包流程

1. 读取备份目录中的 `manifest.sbm`。
2. 写入归档文件头和清单条目数量。
3. 逐项写入条目类型、路径、大小、修改时间、校验值。
4. 如启用 RLE，则先压缩文件内容。
5. 如启用密码，则调用 OpenSSL EVP AES-256-GCM 对载荷进行加密。
6. 对文件条目继续写入文件二进制载荷。
7. 输出打包文件数量、原始字节数和存储字节数。

### 3.5 解包流程

1. 读取并检查归档文件头。
2. 逐项读取清单条目。
3. 对目录条目创建目录。
4. 如条目带有加密标志，则使用同一密码、salt、IV 和认证 tag 调用 OpenSSL EVP 解密并认证。
5. 如条目带有 RLE 标志，则执行解压。
6. 对文件条目写出文件内容。
7. 计算写出文件的校验值。
8. 恢复文件修改时间。
9. 重新生成 `manifest.sbm`。

### 3.6 定时备份流程

1. 用户指定源目录、快照根目录、间隔秒数和执行次数。
2. 程序按次数循环执行备份。
3. 每次备份生成一个独立快照目录。
4. 快照目录名包含时间戳和序号，便于回溯历史版本。
5. 如果用户指定 `--keep=N`，程序会在每次生成快照后删除超出保留数量的旧快照。

## 4. 已实现功能

- 基础备份。
- 基础还原。
- 备份完整性校验。
- 单文件打包。
- 单文件解包。
- RLE 压缩和解压。
- OpenSSL AES-256-GCM 密码加密、解密和完整性认证。
- 空目录保留。
- 按扩展名筛选备份文件。
- 按最大文件大小筛选备份文件。
- 按文件名关键词筛选备份文件。
- 按路径关键词筛选备份文件。
- 按修改时间筛选备份文件。
- 备份目标目录覆盖清理。
- 防止备份目录位于源目录内部。
- 操作统计输出。
- 文件修改时间元数据恢复。
- 周期性定时备份快照。
- 定时备份快照淘汰。
- 原生 C++ Win32 图形界面。
- Windows Forms PowerShell 备用图形界面。

- 备份完整性校验。
